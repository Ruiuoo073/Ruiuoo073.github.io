Node.js 字符串与数组常用方法

Node.js 字符串与数组常用方法

在 Node.js 后端开发中，字符串处理、数组处理是使用率最高的操作。参数接收、数据筛选、接口返回、文件解析、表单校验，全部依赖这两类方法。很多新手写代码卡顿、逻辑繁琐，本质是不会用原生高效方法。
本文承接上文变量、运算符、作用域知识点，汇总工作 100% 常用、无鸡肋的字符串、数组 API，搭配可直接运行的 Node 案例、实战场景、踩坑点，零基础可直接吃透。

一、Node.js 字符串（String）核心知识点

字符串是不可变数据类型，所有字符串方法都不会修改原字符串，只会返回新字符串，这是字符串最核心的特性，也是高频踩坑点。
1.1 字符串基础获取与长度
日常用于获取字符串长度、指定下标字符、字符编码。
// 定义字符串
const str = “Hello Node.js 后端开发”

// 1. 获取字符串长度（最常用：校验账号、密码长度）
console.log(str.length)

// 2. 通过下标获取指定字符
console.log(str[0]) // H
console.log(str[6]) // N

// 3. 获取指定下标字符编码
console.log(str.charCodeAt(0)) // 72（H的ASCII码）

1.2 字符串查找方法（判断包含、定位位置）
用于关键词检索、参数匹配、文件名判断、接口字段校验。
const str = “Node.js 是后端开发核心技术”

// 1. indexOf(关键词)：查找下标，找不到返回 -1
console.log(str.indexOf(“Node”)) // 0
console.log(str.indexOf(“Java”)) // -1

// 2. includes(关键词)：判断是否包含，返回布尔值（开发首选）
console.log(str.includes(“后端”)) // true
console.log(str.includes(“前端”)) // false

// 3. startsWith / endsWith：判断开头、结尾
console.log(str.startsWith(“Node”)) // true
console.log(str.endsWith(“技术”)) // true

实战场景：判断文件后缀、判断请求参数是否包含敏感词、校验接口路由。
1.3 字符串截取方法（裁剪数据）
三种截取方法，重点掌握slice，适配所有场景。
const str = “20260604 博客开发记录”

// slice(起始下标, 结束下标) 【推荐】支持负数
console.log(str.slice(0, 8)) // 20260604
console.log(str.slice(-4)) // 开发记录

// substring：不支持负数，仅正数截取
console.log(str.substring(0, 8))

// substr(起始, 长度)：按长度截取，兼容性差，不推荐
console.log(str.substr(0, 8))

1.4 字符串替换与清空空格
表单校验、数据清洗、去除首尾空格、替换敏感字符必备。
let str = “ Node.js 基础教程 “

// 1. 去除首尾空格（前端后端通用高频）
console.log(str.trim()) // Node.js 基础教程

// 2. 替换字符
let text = “我喜欢Java，Java很好用”
console.log(text.replace(“Java”, “Node.js”)) // 只替换第一个
console.log(text.replaceAll(“Java”, “Node.js”)) // 全部替换（ES6+）

1.5 字符串分割与大小写转换
// 1. 分割字符串 → 数组（超级常用：拆分参数、拆分文件名）
const str = “张三,李四,王五”
const arr = str.split(“,”)
console.log(arr) // [ ‘张三’, ‘李四’, ‘王五’ ]

// 2. 大小写转换
const word = “NodeJS”
console.log(word.toUpperCase()) // 全部大写
console.log(word.toLowerCase()) // 全部小写

1.6 字符串核心踩坑总结

  • 字符串不可变，所有修改方法必须接收返回值，原数据不变
  • 判断包含优先用 includes，比 indexOf 更直观
  • 清空空格只用 trim()，不要手动截取
  • 分割数据优先 split，是字符串转数组的唯一标准方法

二、Node.js 数组（Array）超全实战方法

数组是后端存储批量数据的核心，接口列表、数据库数据、文件列表、批量参数全部依赖数组操作。数组方法分为：增删改查、遍历、筛选、映射、汇总五大类。
2.1 数组增删改基础方法（原数组改变）
let arr = [10, 20, 30]

// 1. 尾部添加、删除
arr.push(40) // 尾部追加
console.log(arr) // [10,20,30,40]
arr.pop() // 尾部删除
console.log(arr) // [10,20,30]

// 2. 头部添加、删除
arr.unshift(0) // 头部追加
console.log(arr) // [0,10,20,30]
arr.shift() // 头部删除
console.log(arr) // [10,20,30]

// 3. splice 万能修改（删除/插入/替换）
arr.splice(1, 1) // 从下标1开始，删除1个
console.log(arr) // [10,30]

2.2 数组遍历方法（替代 for 循环，开发首选）
后端遍历列表、批量处理数据，90% 场景用这两个方法。
const list = [
{ name: “Node.js”, type: “后端” },
{ name: “Vue”, type: “前端” },
{ name: “React”, type: “前端” }
]

// 1. forEach：纯遍历，无返回值
list.forEach((item, index) => {
console.log(index, item.name, item.type)
})

// 2. for…of：简洁遍历，支持中断（推荐新手）
for (const item of list) {
console.log(item.name)
}

2.3 数组筛选与查找（接口过滤数据核心）
筛选符合条件的数据、查找单个数据，项目最高频 API。
const list = [10, 22, 33, 45, 60]

// 1. filter：筛选所有符合条件的，返回新数组
const newList = list.filter(item => item > 30)
console.log(newList) // [33,45,60]

// 2. find：查找第一个符合条件的元素，找不到返回 undefined
const findItem = list.find(item => item === 22)
console.log(findItem) // 22

// 3. findIndex：查找下标
const index = list.findIndex(item => item === 45)
console.log(index) // 3

实战场景：后台筛选订单、过滤无效参数、查找用户信息、权限匹配。
2.4 数组映射加工（批量改数据）
map 是后端数据格式化核心，批量修改数组每一项，返回新数组，不污染原数据。
const userList = [
{ name: “张三”, age: 18 },
{ name: “李四”, age: 20 }
]

// 批量新增字段、修改字段
const newUser = userList.map(item => {
return {
username: item.name,
userAge: item.age,
status: “正常” // 新增字段
}
})
console.log(newUser)

2.5 数组判断与去重
const arr = [1,2,2,3,3,4]

// 1. includes：判断是否包含元素
console.log(arr.includes(2)) // true

// 2. every：所有元素满足条件才返回true
console.log(arr.every(item => item > 0)) // true

// 3. some：任意一个满足条件就返回true
console.log(arr.some(item => item > 3)) // true

// 4. 数组去重（最简万能写法）
const uniqueArr = […new Set(arr)]
console.log(uniqueArr) // [1,2,3,4]

2.6 数组拼接与转换
const arr1 = [1,2,3]
const arr2 = [4,5,6]

// 1. 数组合并
const allArr = arr1.concat(arr2)
// 扩展运算符更简洁（推荐）
const allArr2 = […arr1, …arr2]

// 2. 数组转字符串
const str = arr1.join(“-“)
console.log(str) // 1-2-3

三、高频组合实战案例（工作直接复用）

结合字符串+数组方法，模拟后端真实数据处理场景。
案例：清洗前端传入的批量用户名
// 前端传入原始字符串
const userStr = “ 张三,李四,李四,王五, ,赵六 “

// 1. 去除首尾空格 + 分割数组
const userArr = userStr.trim().split(“,”)

// 2. 过滤空数据、去重、过滤无效用户名
const res = […new Set(userArr.filter(item => item.trim()))]

console.log(res)
// 最终纯净结果：[ ‘张三’, ‘李四’, ‘王五’, ‘赵六’ ]

四、核心学习总结

  1. 字符串不可变：所有操作返回新字符串，原数据不会修改，必须接收返回值；
  2. 字符串高频三件套：includes 判断、trim 去空格、split 分割数组；
  3. 数组开发四巨头：forEach 遍历、filter 筛选、map 加工、find 查找；
  4. 数组方法优先使用不修改原数组的方法，避免数据污染、逻辑bug；
  5. 字符串+数组组合操作，是后端参数清洗、数据格式化的基础核心能力。
