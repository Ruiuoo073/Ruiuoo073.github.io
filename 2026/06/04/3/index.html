Node.js 函数详解（声明方式、参数、返回值、作用域实战）

函数是Node.js 编程的核心灵魂。

前面学的变量、数据类型、运算符、判断循环、字符串数组，全部都是“原材料”，函数才是用来组装代码、实现功能、封装接口、复用逻辑的核心载体。
后端写接口、写工具方法、处理业务逻辑、拆分代码模块，100% 全部依赖函数。本文从零讲透 Node.js 所有函数用法、区别、实战场景、高频踩坑点。

一、什么是函数？（通俗理解）

函数就是：把一段重复、完整、特定功能的代码打包起来，起个名字，随时调用。
核心好处：

  • 代码复用：不用重复写一堆重复代码
  • 结构清晰：一个函数只做一件事
  • 方便维护：改一处，全局生效
  • 支持传参、返回结果，实现动态逻辑

二、Node.js 三种函数声明方式（必全会）

2.1 普通函数声明（function 关键字）
最基础、兼容性最好、适合业务功能封装。

特点：

  • 支持函数提升（可以先调用、后声明）
  • this 指向动态变化
  • 适合大型业务函数、工具函数
    2.2 函数表达式（匿名函数）
    把函数赋值给变量，更规范、现代项目用的极多。

特点：

  • 不会变量提升（必须先定义再调用）
  • 防止全局函数污染
  • 适合赋值、传参、回调场景
    2.3 箭头函数（ES6 核心，工作最常用）
    简洁、短小、适合回调、遍历、处理数据，前端+后端项目首选。

箭头函数核心特点（面试高频）：

  • 没有自己的 this
  • 没有 arguments
  • 不能当作构造函数
  • 代码极简，适合数据处理、数组方法回调

三、函数参数详解（形参、实参、默认参数）

3.1 形参 & 实参
形参：函数定义时的变量（占位）
实参：函数调用时传入的真实数据

3.2 默认参数（解决不传参 undefined 问题）
业务开发超级常用，防止调用时少传参数导致报错。

3.3 剩余参数 …（接收多个参数）
不确定参数个数时使用，非常适合工具函数封装。

没有 return 的函数，默认返回 undefined
return 会直接终止函数执行

五、函数作用域（变量生效范围）

5.1 全局变量
函数外部定义，所有函数都能访问。

5.2 局部变量（函数内部变量）
仅当前函数内有效，外部无法访问，函数执行完毕自动销毁。

六、匿名函数与自执行函数

6.1 匿名函数
没有名字，多用于回调、参数传递。

6.2 自执行函数（立即执行）
定义完直接执行，用来创建独立作用域，防止变量污染。
