JavaScript

一、JavaScript 是什么？

JavaScript（简称 JS） 是一种运行在浏览器 / 服务器上的编程语言，是网页的 “动作控制器”。
简单理解:

  • HTML = 网页的骨架(文字,图片,按钮长什么样)
  • CSS = 网页的皮肤(颜色,布局,样式)
  • JavaScript = 网页的大脑和手脚(让网页动起来,能交互)

    它是前端开发必学语言，也是全世界最流行、使用最广的编程语言之一。

二、JavaScript 解决什么问题？

它专门解决 “静态网页不会动、不能交互” 的问题。
日常见到的这些功能，全是 JS 做的：

  1. 点击按钮弹出提示、切换页面
  2. 表单验证（比如输入密码太短自动提醒）
  3. 轮播图、滚动动画、下拉菜单
  4. 登录、点赞、收藏、发送评论
  5. 实时刷新数据（外卖进度、聊天消息、股票价格）
  6. 游戏、小程序、APP（很多都是 JS 开发）

    没有 JS，网页就是一张不能点、不能动的静态图片；有了 JS，网页才变成能用、会交互的工具。

五、JavaScript 能做什么？

  • 不只是网页，JS 现在能做全栈开发：
  • 网页前端（主流）
  • 服务器后端（Node.js）
  • 小程序（微信、支付宝、抖音）
  • APP（iOS/Android）
  • 桌面软件（VS Code 就是用 JS 写的）
  • 游戏、数据可视化、人工智能工具
