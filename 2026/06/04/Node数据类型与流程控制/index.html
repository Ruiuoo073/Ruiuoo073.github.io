Node.js 数据类型与流程控制

Node.js 基于 JavaScript 语法，拥有一套完整的数据类型体系和流程控制语法，是编写后端逻辑、接口开发的基础，本文总结日常开发最常用的核心知识点。
一、Node.js 常用数据类型

  1. 数字类型（Number）
    包含整数、小数，对应其他语言的 Integer、Float、Double，统一为 Number 类型。
    // 整数
    let num1 = 0
    let num2 = 999

// 小数
let num3 = 0.1
let num4 = 0.122222
2. 字符串类型（String）
用于存储文本内容，对应 Java 字符串、Char 字符，JS/Node 中没有单独字符类型，统一用字符串。
let str1 = “1”
let str2 = “hello node”
let str3 = ‘a’
3. 布尔类型（Boolean）
只有两个值：true / false，常用于判断条件、状态开关。
let flag = true
let isOpen = false
4. 数组类型（Array）
存储一组有序数据，支持任意类型元素，是开发中最常用的存储结构。
let arr1 = [1, 2, 3]
let arr2 = [“张三”, “李四”]
let arr3 = [1, “文本”, true]
5. 空类型
undefined：变量未赋值；null：手动置空，用于清空数据。
二、流程控制语句
流程控制用于控制代码执行顺序，是逻辑判断、循环遍历的基础。

  1. if / else 条件判断
    满足条件执行对应代码，适用于区间判断、多条件分支。
    let score = 80

if (score >= 60) {
console.log(“及格”)
} else {
console.log(“不及格”)
}
2. for 循环
用于重复执行代码，常用于遍历数组、批量处理数据。
// 基础for循环
for (let i = 0; i < 5; i++) {
console.log(“循环次数：”, i)
}

// 遍历数组
let list = [10, 20, 30]
for (let i = 0; i < list.length; i++) {
console.log(list[i])
}
3. switch 多分支判断
适用于固定值匹配判断，比大量 if else 更简洁。
let day = 1
switch (day) {
case 1:
console.log(“周一”);
break;
case 2:
console.log(“周二”);
break;
default:
console.log(“未知星期”);
}
4. 常用循环写法
forEach、for…in、for…of 常用于数组、对象遍历，是项目开发高频用法。
三、总结

  1. Node.js 数据类型简洁统一，数字不分整数小数，日常重点掌握数字、字符串、数组、布尔类型即可满足绝大多数开发场景；
  2. 流程控制是代码逻辑的核心，if 判断、for 循环、switch 分支是所有业务逻辑的基础；
  3. 熟练掌握数据类型和流程控制，才能实现数据处理、接口逻辑、条件筛选等后端功能。
