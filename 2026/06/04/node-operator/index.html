Node.js 变量、作用域与运算符（超详细实战教程）

变量、作用域、运算符是 Node.js 代码的核心骨架，所有业务逻辑、数据处理、接口开发都基于这三大基础实现。很多新手代码报错、变量冲突、逻辑运算错误，本质都是没吃透这部分知识点。本文结合 Node.js 运行特性，从零详解所有用法、区别、踩坑点，搭配可直接运行的实战案例。
一、Node.js 变量定义与三种声明方式
变量是用于存储数据的容器，Node.js 沿用 JS 三种变量声明关键字：var、let、const，三者在作用域、变量提升、重复声明、修改规则上有本质区别，开发中优先使用 const，其次 let，禁止使用 var。
1.1 var（旧版声明，不推荐）
var 是 ES5 及之前的变量声明方式，存在很多设计缺陷，现代 Node.js 开发已完全淘汰。
核心特性：

  • 函数级作用域，无块级作用域
  • 支持变量提升，声明前可访问（值为 undefined）
  • 允许重复声明同一变量，无报错，会覆盖旧值
  • 可重复赋值修改
    // var 重复声明不报错
    var name = “张三”
    var name = “李四”
    console.log(name) // 输出：李四

// 变量提升现象
console.log(age) // 输出：undefined，不会报错
var age = 18

致命缺点：容易造成全局变量污染、变量冲突、逻辑混乱，项目越大 bug 越多。
1.2 let（可变变量，推荐使用）
let 是 ES6 新增的变量声明方式，专门解决 var 的缺陷，用于声明可以被重新赋值的变量。
核心特性：

  • 块级作用域（{} 内部生效）
  • 不存在变量提升，暂时性死区，声明前无法访问
  • 禁止重复声明同一变量，重复声明直接报错
  • 支持重新赋值修改
    // 1. 块级作用域验证
    if (true) {
    let num = 100
    console.log(num) // 输出：100（块内可访问）
    }
    // console.log(num) // 报错：num is not defined（块外无法访问）

// 2. 可重复赋值
let count = 1
count = 2
console.log(count) // 输出：2

// 3. 禁止重复声明
// let count = 3 // 直接报错：Identifier ‘count’ has already been declared

1.3 const（常量，默认首选）
const 是 ES6 新增的常量声明方式，用于声明一旦赋值、无法修改内存地址的变量，开发中 80% 场景都用 const。
核心特性：

  • 块级作用域，和 let 一致
  • 无变量提升，暂时性死区
  • 禁止重复声明
  • 必须初始化赋值，不能只声明不赋值
  • 基本数据类型无法修改值，引用数据类型（数组、对象）可修改内部属性
    // 1. 必须初始化
    // const name // 报错：Missing initializer in const declaration

// 2. 基本类型不可修改
const PI = 3.14
// PI = 3.1415 // 报错：Assignment to constant variable

// 3. 引用类型可修改内部数据（重点踩坑点）
const arr = [1, 2, 3]
arr.push(4) // 允许修改内部元素
console.log(arr) // 输出：[1,2,3,4]

// arr = [5,6] // 报错：不允许修改数组内存地址

二、Node.js 三大作用域（核心重点）
作用域决定了变量的可访问范围，是解决变量冲突、全局污染、闭包问题的核心，Node.js 中分为：全局作用域、函数作用域、块级作用域。
2.1 全局作用域
在所有函数、代码块外部定义的变量，属于全局变量，整个文件任意位置都可访问。
Node.js 特性：全局变量会挂载到 globalThis 对象，区别于浏览器的 window。
// 全局变量
const siteName = “Ruiuoo的博客”

function test() {
// 函数内部可直接访问全局变量
console.log(siteName)
}
test() // 输出：Ruiuoo的博客

// 挂载到全局对象
console.log(globalThis.siteName) // 输出：Ruiuoo的博客

2.2 函数作用域
在函数内部定义的变量，仅在当前函数内部可访问，函数执行结束后变量销毁，外部无法访问。
function getUser() {
// 局部变量（函数作用域）
let username = “小明”
console.log(username) // 内部可访问
}
getUser()
// console.log(username) // 报错：外部无法访问函数局部变量

2.3 块级作用域（ES6 核心）
由 {} 包裹的代码块（if、for、while、单独代码块）形成的作用域，let/const 生效，var 不生效。
// 块级作用域生效案例
for (let i = 0; i < 3; i++) {
console.log(i)
}
// console.log(i) // 报错：i 仅在循环块内生效

// var 无块级作用域（踩坑案例）
for (var j = 0; j < 3; j++) {}
console.log(j) // 输出：3，泄露到全局

2.4 作用域链（面试高频）
当代码需要读取变量时，会从当前作用域层层向外查找，直到全局作用域，找不到则报错，这个层级关系就是作用域链。
let a = 10
function fn1() {
let b = 20
function fn2() {
let c = 30
// 查找顺序：自身c => 外层b => 全局a
console.log(a, b, c) // 10 20 30
}
fn2()
}
fn1()

三、Node.js 完整运算符大全（实战全覆盖）
运算符用于数据运算、逻辑判断、赋值操作，是编写业务逻辑的基础，下面分类详解所有常用运算符及踩坑点。
3.1 算术运算符
用于数字加减乘除运算，包含：+、-、*、/、%、++、–
let a = 10
let b = 3

console.log(a + b) // 13 加法
console.log(a - b) // 7 减法
console.log(a * b) // 30 乘法
console.log(a / b) // 3.3333 除法
console.log(a % b) // 1 取余（取模，常用于判断奇偶）

// 自增自减
let num = 1
num++ // 后置自增，先取值后+1
++num // 前置自增，先+1后取值
console.log(num) // 3

踩坑点：数字 + 字符串 = 字符串拼接，而非加法
console.log(10 + “20”) // 输出：1020（拼接）
console.log(10 - “20”) // 输出：-10（自动转数字运算）

3.2 赋值运算符
用于给变量赋值，包含：=、+=、-=、*=、/=、%=
let num = 10
num += 5 // 等价于 num = num + 5
num -= 2 // 等价于 num = num - 2
num *= 2 // 等价于 num = num * 2
console.log(num) // 26

3.3 比较运算符（返回布尔值）
用于比较两个值的大小、相等关系，返回 true/false，是条件判断的核心。

  • ==：弱相等，只比较值，自动转换数据类型
  • ===：强相等，同时比较值和数据类型（开发首选）
  • !=、!==：不等、严格不等

  • 、<、>=、<=：大小比较
    // 弱相等（踩坑）
    console.log(10 == “10”) // true（自动转类型，只比值）

// 严格相等（推荐）
console.log(10 === “10”) // false（值相同，类型不同）
console.log(10 === 10) // true

3.4 逻辑运算符（条件判断核心）
用于拼接多个判断条件，包含：&&（与）、||（或）、!（非）
let score = 80

// && 与：全部条件为true才为true
console.log(score > 60 && score < 90) // true

// || 或：任意一个条件为true就为true
console.log(score < 60 || score > 70) // true

// ! 非：取反
console.log(!(score > 90)) // true

短路特性（高频考点/实战用法）：

  • a && b：a 为 false，直接返回 a，不执行 b
  • a || b：a 为 true，直接返回 a，不执行 b
    3.5 三元运算符（简化 if else）
    唯一的三目运算符，用于简化简单的双分支判断，语法：条件 ? 成立执行 : 不成立执行
    let score = 59
    let res = score >= 60 ? “及格” : “不及格”
    console.log(res) // 输出：不及格

四、开发高频踩坑总结

  1. 变量声明规范：全程放弃 var，固定使用 const 声明常量、let 声明可变变量
  2. 作用域避坑：循环、判断内部变量必须用 let/const，防止变量泄露全局
  3. 相等判断：业务判断一律用 === 严格相等，避免隐式类型转换 bug
  4. 运算避坑：数字和字符串混合运算注意拼接问题，手动转换类型
  5. const 特性：const 声明的数组/对象可改内部数据，不可直接赋值覆盖
    五、学习总结
  6. 变量是数据存储的核心，let/const 的块级作用域彻底解决了旧版 var 的全局污染问题，是现代 Node.js 开发的标准写法；
  7. 作用域控制变量的访问权限，作用域链是变量查找的底层逻辑，理解后可解决 90% 的变量报错问题；
  8. 各类运算符支撑所有数据运算和逻辑判断，严格相等、短路运算、三元运算是项目开发中最高频的用法；
  9. 掌握以上知识点，可独立编写完整的分支、循环、数据运算逻辑，为后续函数、数组方法、接口开发打下基础。
