cloudflare

一、云服务

p:服务商把电脑、硬盘、宽带放机房，租给你远程使用 = 云服务

  1. 云服务器 (ECS)：远程一台虚拟电脑，可以装系统跑网站、程序
  2. 对象存储 (S3)：远程超大硬盘，专门存图片、视频、静态文件（后面存储桶就是它）
  3. CDN/边缘网络：Cloudflare 主打，就近加速用户访问

二、存储桶 & S3 存储

  1. S3 是什么
    S3 是亚马逊 AWS 定的一套存储接口标准，全称简单理解：通用云端文件存储协议
    现在几乎所有厂商（阿里云 OSS、腾讯 COS、Cloudflare R2）都兼容 S3 协议，S3 = 行业通用存文件规范
  2. 存储桶(Bucket)
    存储桶 = 云端硬盘根文件
  • 类比: 你的电脑D盘根目录[D:\]就是一个桶，桶里面可以新建文件夹、放图片 / JS / 视频
  • 规则:
  1. 一个账号可以建多个桶,桶名字全球不能重复(类似网盘账号根目录)
  2. 桶里面存的文件叫[对象],所以S3又叫对象存储
    -用处：存网站静态资源（图片、css、js、静态 html）、附件、素材，不适合跑程序，只存文件

    Cloudflare R2、阿里云 OSS 全都是兼容 S3 的存储桶产品。

三、域名、DNS、域名解析

  1. 域名
    [baidu.com],[xxx.vercel.app]就是域名
    IP 是服务器门牌号（数字：180.101.49.11），域名是好记的别名，人记不住数字 IP，所以用域名。
    域名分级：
  • 顶级域: [.com/.org/.app/.cn]
  • 主域名: [abc.com]
  • 子域名” [blog.abc.com、www.abc.com]
  1. DNS是什么
    DNS = 互联网电话簿
    作用：把域名翻译成服务器 IP 地址。
    输入[baidu.com]，DNS 查簿子找到对应的 IP，电脑才知道连哪台服务器。
  2. 域名完整解析过程
    e.g:浏览器打开 [test.com]
  3. 浏览器先查本机缓存：之前访问过就直接拿 IP；没有→下一步
    查本地运营商 DNS（如联通 / 电信 DNS）缓存；没有→向上找根 DNS 服务器
    根服务器告诉：去找[.com]顶级域服务器
    [.com]服务器：去找[test.com]的域名服务商 DNS（你在 Cloudflare 填解析记录的服务器）
    Cloudflare DNS 查到你设置的 A 记录：[test.com → 1.1.1.1]（目标服务器 IP）
    原路把 IP 一层层传回浏览器
    浏览器拿着 IP 去连接对应服务器，打开网站

    A 记录：域名→IPv4 地址（填服务器 IP）
    CNAME：域名→另一个域名（常用在 Vercel/Cloudflare，绑定域名不用填 IP）

Cloudflare 功能

Cloudflare = 全球分布式边缘网络厂商，全球几百个城市边缘节点
功能:

  1. 免费 DNS 解析：域名 NS 改成 Cloudflare，在后台管理 A/CNAME 记录
  2. CDN 全球加速（边缘节点）：网站静态资源缓存到全球各地节点，用户就近访问
  3. 防护（CC/DDOS/ 防火墙 / WAF）：黑客攻击先打到 Cloudflare 节点，源站隐藏 IP 不暴露，防被打崩
  4. 免费 SSL 证书：一键开启 HTTPS（小锁图标），不用自己买证书
  5. 附属产品:
  • R2 存储：兼容 S3 的对象存储桶，存静态文件
  • Pages：免费静态网站托管（和 Vercel 同类）
  • Workers：边缘函数，在全球节点跑轻量代码

五、边缘节点(CDN)

边缘节点 = 遍布全世界各个城市的缓存小服务器
e:我的源站服务器在武汉

  1. 北京用户访问网站：资源存在北京边缘节点，不用连武汉源站，秒开
  2. 美国用户访问：调取美国节点缓存文件，跨洋不用直连国内服务器
  • 没缓存的资源：节点回源（去原服务器拉文件，之后缓存下来下次复用）

    Cloudflare、Vercel 全部靠边缘节点实现全球加速。

  • 源站：原始存放网站代码的服务器（比如 Vercel 源站、自己国内服务器）；
  • 边缘：用户家门口的中转站。

六、Vercel 使用 & 介绍（前端静态网站神器）

1. Vercel 是什么
美国云平台，主打前端静态项目一键部署（Vue/React/Hexo/HTML 静态博客），全球边缘 CDN，免费额度够用。

  • 前身是 Next.js 开发团队做的，天生适配前端框架。
    2. 怎么使用
  1. 代码上传 GitHub/Gitee
  2. Vercel 绑定 GitHub 账号，导入项目仓库
  3. 一键 Deploy（部署），自动打包编译，分配免费二级域名 [xxx.vercel.app]
  4. 自定义域名：在 Vercel 填域名，去域名 DNS 后台添加 CNAME 记录指向 Vercel 地址即可
  5. Vercel 特点
    自动全球边缘节点分发，国内搭配 Cloudflare 可优化访问速度
    代码提交 GitHub 自动更新部署（CI 自动化）
    静态站点免费，不用买服务器、不用配置环境
    • 链路: Hexo 写博客静态代码 → 上传 Github → Vercel 自动部署，生成[xxx.vercel.app]→ 买自定义域名[abc.com] → DNS 接入Cloudflare→ Cloudflare 做解析 + CDN 加速，资源缓存到全球边缘节点→ 博客图片资源丢进R2 存储桶（S3），博客引用桶内图片地址
