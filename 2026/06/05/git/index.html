Git版本控制

一、什么是 Git？

Git 是一个免费、开源、分布式的「版本控制系统」。
简单比喻:

  • 你写文档、写代码、做设计，每一次修改都能自动记录
  • 能随时回到过去任何一个版本
  • 多人一起改同一个文件不会乱
  • 所有历史记录都存在本地，不怕丢
    它不是 GitHub！
  • Git = 工具(装在你电脑里)
  • GitHub = 云端仓库(用来放 Git 管理的文件)

二、Git 解决了什么问题？

这是 Git 最厉害的地方，直接解决开发/写作中最痛的 5 个问题：

  1. 再也不用手动命名：最终版、最终版 2、真最终版
    Git 会自动保存所有版本，你随时切回去。
  2. 误删 / 改错能一键恢复
    不管改坏多少，都能回到上一个正常版本。
  3. 多人协作不会乱
    多人同时改同一个文件，Git 会智能合并，不会覆盖别人的工作。
  4. 本地就有完整历史
    不联网也能查看版本、回滚、对比修改。
  5. 分支开发，不影响主版本
    你可以开一个 “实验分支” 随便改，不影响正在使用的稳定版本。

四、Git 使用流程

  1. 新建一个文件夹
  2. 打开终端 / CMD 进入文件夹
  3. git init
  4. 写文件 / 改代码
  5. git add .
  6. git commit -m “第一次提交”
  7. 继续修改
  8. 再 git add .
  9. 再 git commit -m “更新了XX功能

五、Git 工作原理

  • 工作区：你正在编辑的文件
  • 暂存区：git add 后放这里
  • 本地仓库：git commit 后永久保存版本
